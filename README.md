# screenshare_dual_path

A minimal Android sample app for launching one of two OpenGL child activities on a caller-provided display ID.

## Package identity

The APK namespace and application ID are both:

```text
com.example.screenshare.dualpath
```

The launcher activity is declared explicitly as:

```text
com.example.screenshare.dualpath.MainActivity
```

If Android reports a crash that references an older component such as `com.example.dualpath.dualpath.MainActivity` or an older package such as `com.example.screenshare.dualpath`, uninstall the stale APK first and then install the rebuilt APK.
